# 🧪 Руководство по тестированию Robokassa API

## Быстрый старт

### 1. Запуск локального сервера
```bash
cd robokassa-api
npm install
npm start
```

### 2. Открытие тестовой страницы
Перейдите в браузере по адресу: **http://localhost:3000/test**

### 3. Тестирование генерации ссылок
1. Нажмите кнопку **"📋 Загрузить конфигурацию"** для проверки настроек
2. Заполните форму тестовыми данными:
   - Email: `test@example.com`
   - Телефон: `+79001234567`
   - Сумма: `1000`
   - Описание: `Тестовый платеж`
3. Нажмите **"💳 Сгенерировать платежную ссылку"**
4. Если все настроено правильно, вы получите рабочую ссылку на оплату

## Проверка конфигурации

### Переменные окружения
Убедитесь, что в файле `.env` установлены:
```env
ROBOKASSA_LOGIN=ваш_логин
ROBOKASSA_TEST_PASSWORD1=тестовый_пароль_1
ROBOKASSA_TEST_PASSWORD2=тестовый_пароль_2
ROBOKASSA_TEST_MODE=true
RAILWAY_API_URL=https://minenkovrehab-production-15cc.up.railway.app
```

### API Endpoints для ручного тестирования

#### 1. Проверка конфигурации
```bash
curl http://localhost:3000/api/robokassa/config
```

#### 2. Генерация платежной ссылки
```bash
curl -X POST http://localhost:3000/api/robokassa/generate-payment-url \
  -H "Content-Type: application/json" \
  -d '{
    "email": "test@example.com",
    "phone": "+79001234567",
    "amount": 1000,
    "description": "Тестовый платеж"
  }'
```

#### 3. Проверка подписи
```bash
curl "http://localhost:3000/api/robokassa/verify-signature?outSum=1000&invId=12345&signature=YOUR_SIGNATURE&type=result"
```

## Что проверить

### ✅ Успешная генерация ссылки
- [ ] Конфигурация загружается без ошибок
- [ ] Все пароли установлены
- [ ] Генерируется корректная ссылка
- [ ] Ссылка содержит все необходимые параметры
- [ ] Тестовый режим активен

### ✅ Структура ссылки
Сгенерированная ссылка должна содержать:
- `MerchantLogin` - ваш логин
- `OutSum` - сумма платежа
- `InvId` - уникальный ID заказа
- `Description` - описание
- `SignatureValue` - подпись
- `SuccURL` - URL успешной оплаты
- `FailURL` - URL неудачной оплаты
- `Email` и `Phone` - контактные данные
- `IsTest=1` - флаг тестового режима

### ✅ Проверка Success/Fail страниц
1. Перейдите по ссылке: `http://localhost:3000/payment/success`
2. Перейдите по ссылке: `http://localhost:3000/payment/fail`

## Возможные проблемы

### ❌ "Настройки Robokassa не сконфигурированы"
- Проверьте файл `.env`
- Убедитесь, что `ROBOKASSA_LOGIN` установлен
- Проверьте пароли для тестового режима

### ❌ "Ошибка валидации"
- Проверьте формат email
- Убедитесь, что сумма больше 0
- Проверьте формат телефона

### ❌ Ссылка не работает
- Убедитесь, что в Robokassa настроены правильные URL для Success/Fail
- Проверьте, что тестовый режим включен в личном кабинете Robokassa

## Следующие шаги

1. **Тестирование в Robokassa**: Перейдите по сгенерированной ссылке и проведите тестовый платеж
2. **Проверка Result URL**: Убедитесь, что Robokassa может отправлять уведомления на ваш сервер
3. **Настройка продакшена**: Переключите `ROBOKASSA_TEST_MODE=false` и используйте боевые пароли
