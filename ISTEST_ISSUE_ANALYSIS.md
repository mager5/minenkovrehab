# 🔍 Анализ проблемы с %27 в параметре IsTest

## 📋 Описание проблемы
Пользователь обнаружил, что в URL Robokassa появляется `IsTest=1%27` вместо ожидаемого `IsTest=1`.

**Проблемный URL:**
```
https://auth.robokassa.ru/Merchant/Index.aspx?MerchantLogin=Minenkov-2&OutSum=2950.00&invoiceID=1724896587&Description=Test+payment&SignatureValue=5EC6B0E48989D6DEDEA906346D1AA647&IsTest=1%27
```

## 🔬 Проведенный анализ

### 1. Проверка кодовой базы
- ✅ Все файлы используют корректный формат `IsTest=1` или `'1'`
- ✅ Нет мест с неправильным добавлением кавычек
- ✅ URLSearchParams используется корректно

### 2. Тестирование Railway API
- ✅ Текущий Railway API работает корректно
- ✅ Генерирует URL без лишних символов %27
- ✅ Параметр IsTest корректно устанавливается в значение "1"

### 3. Диагностические тесты
- ✅ Подтверждено, что %27 появляется при добавлении одинарной кавычки к значению
- ✅ Проблема воспроизводится только при значении "1'" вместо "1"
