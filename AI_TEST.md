# Редактор главной страницы — ai-test

Запуск: npm ci, затем npm run ai:test. Открыть http://127.0.0.1:4310/. Для локальных тестов используется Node.js 24.

В чате можно описывать изменения главной обычным языком:

- тексты, заголовки, абзацы, подписи кнопок и ссылки;
- шапка, логотип из файлов сайта, меню, закрепление шапки, подвал и контакты;
- цвета, размеры заголовков и текста, отступы, высота секций, скругления;
- фотографии из текущих файлов public/images, фон или фото слева/справа;
- карточки, статистика, FAQ, добавление, скрытие, удаление и порядок блоков.

Кнопка «Изменить главную» применяет проверенные правки. «Отменить последнее» возвращает целое предыдущее состояние; сохраняется до 20 шагов. «Свернуть редактор» позволяет рассмотреть страницу. История переписки и черновик сохраняются только в текущей вкладке.

Кнопка «Проверить без AI» демонстрирует светлый первый экран и добавление кнопки «Выбрать программу», сохраняя текущий заголовок. Демонстрацию можно отменить.

«Подключить AI» принимает OpenAI API-ключ в отдельном поле. Ключ остаётся в памяти локального сервера до его перезапуска, не записывается в файлы/Git/sessionStorage и не возвращается браузеру. Повторный ввод при обновлении кода не нужен, пока серверный процесс работает. Альтернатива — OPENAI_API_KEY в окружении запуска.

При AI-запросе в OpenAI отправляются команда, несколько последних сообщений, текущее содержимое главной (включая публичные контакты шапки/подвала), схема страницы и список локальных изображений. В интерфейсе это указано перед отправкой. Используется Responses API, store=false, серверный Authorization и строгая JSON-схема. Модель по умолчанию — gpt-5-mini.

## Хранение изменений и ограничения

Текущее состояние главной — content/ai-home-page.json. Предыдущие состояния — .ai-test-history/, исключённая из Git. Старый content/ai-home-title.json сохранён как часть первого эксперимента, новый редактор из него не читает. При переходе сохранён заголовок, который пользователь изменил в первом тесте. Локальные пользовательские правки не публикуются автоматически.

Модель возвращает точечные JSON Patch операции. Они применяются к копии, затем проверяется вся страница, существование изображений, единственный видимый h1, уникальность блоков, ссылки и допустимые значения оформления. Исполняемый код, произвольные CSS/HTML, файловые пути, API, платежи и кабинеты недоступны. Некорректные или устаревшие изменения отклоняются целиком. Параллельные изменения блокируются, файл сохраняется атомарно.

Редактор работает только в локальной dev-копии на ветке ai-test. Launcher слушает 127.0.0.1, не допускает .env-файлов и не передаёт рабочие ключи/настройки сервисов. Все API, кроме /api/ai-test, и вход/кабинет заблокированы. Host/Origin проверяются. Автодеплой ai-test отключён. Другие страницы сохраняют прежнюю шапку/подвал; в этом этапе редактируется главная. Добавление новых файлов изображений, произвольных компонентов и серверных функций пока не реализовано.

Основа frontend — отдельная копия исходников из локального dd8354d, метка которого стоит на frontend-образе HostKey. Точное соответствие всех входных файлов production-сборке не подтверждено. Это изолированный эксперимент. Серверный снимок сохранён отдельно в server-sync-2026-10-31.

## Проверки 31 октября 2026

16 тестов прошли: правки нескольких элементов, шапка/подвал, FAQ, перестановка и скрытие блоков, отмена, сохранение, устаревшие версии, запрет production/другой ветки, отсутствие ключа, небезопасные ссылки/пути/стили, отсутствующие картинки, неполные/ошибочные ответы и блокировка параллельных записей. Контракт OpenAI проверен с подставным транспортом.

В браузере проверены светлый первый экран, появление новой кнопки, сохранение текущего пользовательского заголовка и восстановление прежнего вида через отмену. TypeScript и целевая проверка ESLint пройдены.

Ключ пользователя подключён. Пробный живой запрос новой версии не выполнен: автоматическая проверка отклонила отправку содержимого и контактных данных главной в OpenAI до отдельного согласия пользователя. Это не проверка провайдера и не ошибка ключа.

Документация API: https://developers.openai.com/api/docs/guides/structured-outputs и https://developers.openai.com/api/docs/models/gpt-5-mini.
