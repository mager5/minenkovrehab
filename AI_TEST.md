# Редактор выбранного элемента — ai-test

Запуск: `npm ci`, затем `npm run ai:test`. Открыть http://127.0.0.1:4310/.

Для ручной правки нажмите на текст главной страницы: он редактируется прямо на своём месте, рядом появляются «Сохранить» и «Отмена». Клик по другому тексту сразу переключает редактирование без «Отмены»: несохранённый черновик предыдущего текста сбрасывается, сохранённые правки остаются. Повторный клик внутри текущей надписи сохраняет её черновик. Это работает для заголовков, абзацев, пунктов списков, надписей кнопок/ссылок, шапки и подвала. Правка касается отдельного текстового узла, сохраняет иконки, стили и соседние надписи; переход по ссылке при редактировании перехватывается. До 2000 символов на надпись, без HTML. AI и ключ для ручной правки не нужны. При активном режиме выделения клик выбирает элемент для чата. Редактор подключён только в `src/app/page.tsx`, остальные страницы не меняются.

1. Нажать «Выделить элемент» в шапке. Навести курсор и нажать на надпись, картинку или контейнер. «Родитель» выбирает кнопку или контейнер целиком. Escape завершает выбор без изменения страницы.
2. «Добавить в чат» прикрепляет выбранный элемент. Написать команду и нажать «Применить к элементу».
3. Подключить OpenAI API-ключ в отдельном поле. На macOS ключ сохраняется в системной «Связке ключей» и автоматически загружается после перезапуска. В файлы проекта, Git и браузерное хранилище не записывается. Нативный помощник компилируется при запуске в игнорируемый `.ai-runtime`; ключ передаётся ему по приватному stdin, без аргументов процесса. При отказе хранилища подключение не считается успешным. На других ОС ключ хранится в памяти процесса. Выбор элемента и черновик команды сохраняются в sessionStorage текущей вкладки. Без подключения кнопка открывает настройки, не блокируется молча.
4. Микрофон начинает запись только по нажатию. Повторное нажатие завершает её; распознанный текст появляется в поле команды, его можно проверить перед применением. Требуется разрешение браузера. Ограничение: 60 секунд / 5 МБ. Сервер отправляет запись в OpenAI для распознавания и не сохраняет её в файл.
5. «Отменить» возвращает предыдущую правку (до 20 шагов).

Исходная разметка и оформление сохранены. По умолчанию правок нет. Изменяются только явно запрошенные свойства выбранного элемента. Цвет/типографику надписи можно менять отдельно; фон и размеры кнопки — выбрав кнопку целиком. Поддерживаются текст, основные стили, ссылки и существующие локальные картинки. Произвольный JS, новая структура страницы и загрузка новых изображений через команды не поддерживаются.

Правки записываются в `content/ai-element-overrides.json`; история отмены — в игнорируемый `.ai-element-history.json`. Команды не запускают код, Git или операции сервера. Данные выбранного элемента и команда передаются в OpenAI Responses API (`store=false`, строгая JSON-схема), голос — в Audio Transcriptions (`gpt-transcribe`). Ключ передаётся провайдеру только сервером.

## Перестановка блоков главной

В мини-редакторе включите «Переставить блоки». Появятся ручки с точками: перетащите ручку на соседний блок в том же контейнере. Линия показывает место вставки, Esc или отпускание вне контейнера отменяет перенос. На ручке также работают стрелки клавиатуры.

Доступны шесть групп: пять секций главной, три пункта первого экрана, две кнопки первого экрана, четыре карточки услуг, четыре повода обращения и четыре показателя статистики. Новые контейнеры и перенос между группами не создаются. На время ручного ввода текста и AI-выделения ручки отключены.

Порядок сохраняется сразу и входит в общую историю «Отменить» вместе с текстом и стилями. Перестановка управляется React со стабильными ключами, фактический порядок DOM меняется; логические исходные индексы сохраняют привязку старых текстовых правок к их карточкам. Файл с overrides тот же, новая опциональная запись layout не меняет старые данные. На других страницах и вне тестового режима порядок исходный.


## Удаление и история шагов

В режиме «Переставить блоки» наведите курсор на ручку: рядом появится крестик. С клавиатуры он доступен через Tab, на сенсорном экране показывается вместе с ручкой. Нажатие открывает небольшое подтверждение «Удалить блок?» с названием кандидата. До явного «Удалить» блок не меняется; «Отмена», Esc и клик снаружи закрывают подтверждение.

Удаление отдельного элемента или целого раздела сохраняется в layout.hidden внутри общего snapshot. Контент не уничтожается: исходный React-узел и текстовые правки остаются, а «Отменить» восстанавливает его место, текст и оформление. Если удалены все элементы группы, исчезает также пустой контейнер. Сервер принимает удаление только с confirmed=true, проверяет группу, исходный индекс, ветку, Origin/Host и revision.

В мини-редакторе «История действий» показывает последние 20 шагов: изменения текста, оформление, перестановки и удаления. Общая кнопка «Отменить» возвращает каждый шаг по очереди; история и удалённое состояние переживают обновление страницы. Рабочий сайт и другие страницы не меняются.
