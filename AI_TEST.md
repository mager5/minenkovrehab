# Эксперимент с заголовком — ai-test

Запуск: `npm ci`, затем `npm run ai:test`. Открыть http://127.0.0.1:4310/.

1. «Проверить без AI» меняет заголовок на фиксированный тестовый текст.
2. «Подключить AI» принимает OpenAI API-ключ в отдельном поле. Ключ остаётся только в памяти локального сервера, исчезает после перезапуска и не сохраняется в файлах, Git или браузерном хранилище. Альтернатива — OPENAI_API_KEY в окружении процесса.
3. Ввести «Поменяй заголовок на …» и нажать «Изменить через AI».
4. «Вернуть заголовок» восстанавливает исходный текст.

Результат записывается в `content/ai-home-title.json`, из которого главная берёт h1. После изменения можно проверить `git diff` и сохранить результат обычным коммитом. Чат не выполняет Git-команды, не запускает произвольный код и не имеет доступа к другим файлам.

## Изоляция и происхождение копии

Точный состав входных файлов production-сборки не подтверждён. Это кандидат для локального эксперимента, а не проверенная полная копия production. Серверные исправления Caddy/API/worker сохранены отдельно в ветке `server-sync-2026-10-31` и сюда не переносились.

Приложение слушает только 127.0.0.1. Launcher допускает только ветку ai-test, отказывается запускаться с .env-файлами и передаёт минимальное окружение без ключей рабочих сервисов. Все /api, кроме /api/ai-test, и разделы входа/кабинета блокируются локальным proxy. API редактирования работает только при AI_TEST_ENABLED=1 и NODE_ENV=development, повторно проверяет ветку и Origin/Host. Vercel-автодеплой ai-test отключён; workflow GitHub не публикуют эту ветку. Production, база, реальные пользователи, платежи и письма в эксперименте не используются.

AI вызывает OpenAI Responses API с серверным Authorization, store=false и строгой JSON-схемой. Сервер принимает только простой заголовок до 160 символов; HTML, управляющие символы и произвольные действия запрещены. Модель по умолчанию — gpt-5-mini. Документация: https://developers.openai.com/api/docs/guides/structured-outputs и https://developers.openai.com/api/docs/models/gpt-5-mini.
