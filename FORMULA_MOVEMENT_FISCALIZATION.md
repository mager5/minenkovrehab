## Примеры платежных ссылок

### Тестовые результаты

- ✅ **2-й уровень**: Платежная ссылка создана успешно

### Структура платежной ссылки

Каждая ссылка содержит:
- `MerchantLogin`: Идентификатор магазина
- `OutSum`: Сумма платежа (6000.00 ₽)
- `invoiceID`: Уникальный номер счета
- `Description`: Описание с указанием конкретного уровня
- `Receipt`: JSON с данными для фискализации
- `SignatureValue`: Контрольная сумма
- `IsTest`: Флаг тестового режима

## Безопасность

- Все платежные ссылки генерируются с корректной контрольной суммой
- Используется тестовый режим Robokassa для безопасного тестирования
- Описания корректно кодируются в URL для поддержки русских символов
