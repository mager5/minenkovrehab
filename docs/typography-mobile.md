## Цель

Устранить «прыжок» размера основного текста на мобильных (14 ↔ 16px) и зафиксировать предсказуемую типографику для touch‑устройств с соблюдением читаемости и доступности.

## Причины скачков 14 ↔ 16px

- Смешение `text-sm` (14px) и `text-base` (16px) в контенте, особенно в длинных текстовых блоках.
- Разные брейкпоинты и ориентация устройства: в ландшафте некоторые устройства попадают в более широкий диапазон, что визуально «переключает» типографику.
- Автокоррекция размеров текста браузером (text autosizing / font boosting). Для этого важны `viewport` и `text-size-adjust`.

## Принципы мобильной типографики (UX/UI)

### Рекомендации размеров

- Основной текст: 16px (минимум для комфортного чтения).
- Подписи/вторичный текст: 14px.
- Заголовки: 20–24px для секций, 30–36px для главных заголовков (зависит от иерархии).

### Межстрочный интервал

- Основной текст: 1.5–1.7.
- Подписи: 1.35–1.5.
- Длинные списки: ближе к 1.6 для снижения «слипания».

### Веса и контраст

- Основной текст: 400–500.
- Акценты/подзаголовки: 600.
- Контраст текста: не ниже WCAG 2.1 AA (обычный текст ≥ 4.5:1, крупный текст ≥ 3:1).

## Практика для iOS/Android

- Не блокировать масштабирование (не использовать `user-scalable=no`), это ухудшает доступность.
- Явно задавать `text-size-adjust: 100%` и `-webkit-text-size-adjust: 100%`, чтобы снизить влияние автоподстройки.
- Для форм: размеры шрифта в `input/select/textarea` держать ≥ 16px на мобильных, чтобы избежать авто‑зума iOS.

## Реализация в проекте

### CSS‑переменные

В `src/app/globals.css` заданы размеры/line-height через CSS‑переменные:

- `--fs-base`, `--lh-base` для основного текста
- `--fs-sm`, `--lh-sm` для вторичного текста
- `--fs-xs`, `--lh-xs` для подписей

Для touch‑устройств (coarse pointer) в диапазоне до 1024px размеры `sm/xs` повышаются, чтобы основной контент не «съезжал» к 14px.

### Tailwind

В `tailwind.config.js` токены `text-xs/text-sm/text-base/...` привязаны к CSS‑переменным, чтобы типографику можно было менять централизованно без массовых правок компонентов.

## Проверка соответствия WCAG 2.1 (читаемость)

- Базовый текст 16px, line-height 1.5+.
- Контраст для серого текста проверять на фоне карточек/секций (особенно `text-gray-600` и светлых фоновых блоков).
- Не отключать масштабирование и не фиксировать `maximum-scale=1`.
