## 🔍 Основные проблемы

В ходе аудита были выявлены критические несоответствия, которые могли привести к **исчезновению номенклатуры из чека** или **отказу в регистрации чека** со стороны ОФД:

1.  **Неверный ИНН**: Использовался тестовый ИНН `000000000000`. ОФД отклоняет чеки с неверным ИНН.
2.  **Конфликт налогообложения**:
    *   Указана система налогообложения (SNO): `osn` (Общая).
    *   Указана ставка НДС: `none` (Без НДС).
    *   *Проблема*: ОСН подразумевает наличие НДС (20% или 0%). Сочетание "ОСН + Без НДС" является некорректным для большинства случаев (если нет специального освобождения).
3.  **Несоответствие документации**:
    *   В документации (`RECEIPT_INTEGRATION_GUIDE.md`) указан метод расчета `full_payment` (Полный расчет) и ставка `vat20`.
    *   В коде использовался `full_prepayment` (Полная предоплата) и `none` (Без НДС).

## 🛠 Выполненные изменения

В файл `robokassa-api/utils/signature.js` внесены изменения для корректной работы фискализации.

### Установленные параметры (по умолчанию)
Теперь код использует ваши реальные реквизиты без необходимости настройки переменных окружения (хотя их использование по-прежнему рекомендуется):

| Параметр | Старое значение (было) | Новое значение (стало) |
| :--- | :--- | :--- |
| **ИНН** | `000000000000` (Тестовый) | `262703733425` (ИП Миненков В.В.) |
| **Налогообложение** | `osn` (Общая) | `usn_income` (УСН Доходы) |
| **НДС** | `none` (с ошибкой логики) | `none` (Без НДС, корректно) |
| **Тип оплаты** | `full_prepayment` (Предоплата) | `full_payment` (Полный расчет) |

### Новые параметры конфигурации (Environment Variables)
Вы можете переопределить эти значения через переменные окружения на сервере, если потребуется:

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `ROBOKASSA_INN` | `262703733425` | Ваш ИНН |
| `ROBOKASSA_SNO` | `usn_income` | Система налогообложения |
| `ROBOKASSA_TAX` | `none` | Ставка НДС |
| `ROBOKASSA_PAYMENT_METHOD` | `full_payment` | Способ расчета |

## 🚀 Инструкция по применению

1.  **Обновленный код уже содержит ваши реквизиты.** Вам достаточно просто **развернуть (задеплоить)** текущую версию приложения на сервере.
2.  Настройка переменных окружения (`ROBOKASSA_INN` и др.) теперь **не обязательна**, так как верные значения прописаны в коде по умолчанию. Однако, хорошей практикой считается хранить конфиденциальные данные в ENV.
