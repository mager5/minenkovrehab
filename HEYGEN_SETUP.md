# Настройка HeyGen API

## Проблема
Возникает ошибка `APIError: API request failed with status 401` при использовании HeyGen Avatar.

## Причина
Не настроен реальный API ключ HeyGen в переменных окружения.

## Решение

### 1. Получите API ключ HeyGen

1. Зарегистрируйтесь на [HeyGen.com](https://heygen.com)
2. Перейдите в раздел API Settings
3. Создайте новый API ключ
4. Скопируйте ключ

### 2. Настройте переменные окружения

Откройте файл `.env.local` и замените:

```env
HEYGEN_API_KEY=your_real_heygen_api_key_here
```

на ваш реальный API ключ:

```env
HEYGEN_API_KEY=ваш_реальный_api_ключ_heygen
```

### 3. Перезапустите сервер разработки

```bash
npm run dev
```

## Что было исправлено

1. ✅ Обновлен компонент `InteractiveAvatar` для получения токена через API маршрут
2. ✅ Настроены правильные ID аватара и голоса в переменных окружения
3. ✅ Удален хардкодированный токен доступа

## Проверка работы

После настройки API ключа:
1. Откройте страницу с аватаром
2. Нажмите на кнопку запуска аватара
3. Аватар должен инициализироваться без ошибок 401

## Дополнительные настройки

В файле `.env.local` также настроены:
- `HEYGEN_AVATAR_ID` - ID используемого аватара
- `HEYGEN_VOICE_ID` - ID голоса аватара

Эти значения можно изменить на другие доступные в вашем аккаунте HeyGen.
