# 🔄 Система Переключения Контента

Эта система позволяет быстро переключаться между двумя версиями контента сайта:
- **🏥 Оригинальный режим** - полноценный медицинский контент
- **🏦 Банковский режим** - нейтральные формулировки для банковских проверок

## 📋 Основные команды

### Переключение на банковский режим
```bash
npm run content:bank
```
Заменяет все на стрейчинг и растяжку:
- "Физическая реабилитация" → "Профессиональный стрейчинг"
- "Лечение и восстановление" → "Развитие гибкости"
- "Травмы и заболевания" → "Растяжка и пластичность"

### Возврат к оригинальному контенту
```bash
npm run content:original
```
Восстанавливает полный медицинский контент из резервных копий.

### Проверка текущего режима
```bash
npm run content:status  
```
Показывает какая версия контента сейчас активна.

## 🛠️ Как это работает

### Файловая структура
```
content/
├── home.json              # Активный файл
├── home-bank.json         # Банковская версия (в .gitignore)
├── home.json.backup       # Резервная копия (создается автоматически)
├── about.json             # Активный файл
├── about-bank.json        # Банковская версия
├── products.json          # Активный файл  
└── products-bank.json     # Банковская версия
```

### Алгоритм переключения

**На банковский режим:**
1. Создается резервная копия оригинального файла (`.backup`)
2. Банковская версия копируется поверх оригинального файла
3. Сайт теперь использует нейтральный контент

**На оригинальный режим:**
1. Оригинальный файл восстанавливается из резервной копии
2. Резервная копия удаляется
3. Сайт возвращается к медицинскому контенту

## 🎯 Когда использовать

### Банковский режим нужен когда:
- Банк запрашивает проверку сайта
- Нужно показать именно стрейчинг без медицинских терминов
- Требуется "фитнес" позиционирование вместо медицинского
- Избежать вопросов о лицензировании медицинской деятельности

### Оригинальный режим для:
- Обычной работы сайта (сейчас тоже стрейчинг)
- Полноценного представления услуг растяжки
- SEO-оптимизации по стрейчинг запросам
- Привлечения людей интересующихся растяжкой

## ⚠️ Важные моменты

### Безопасность данных
- Оригинальные файлы всегда сохраняются в `.backup`
- Банковские версии не попадают в Git репозиторий
- Можно в любой момент вернуться к оригиналу

### Перед развертыванием
```bash
# Проверьте текущий режим
npm run content:status

# При необходимости переключитесь
npm run content:bank      # для банка
npm run content:original  # для обычной работы

# Запустите сборку
npm run build
```

### Автоматизация
Можно добавить в CI/CD pipeline:
```bash
# Перед деплоем на "банковский" домен
npm run content:bank && npm run build

# Перед деплоем на основной домен  
npm run content:original && npm run build
```

## 🔍 Отличия между режимами

| Аспект | Оригинальный режим | Банковский режим |
|--------|-------------------|------------------|
| Заголовок | "Профессиональный Стрейчинг и Растяжка" | "Профессиональный Стрейчинг и Растяжка" |
| Описание услуг | Стрейчинг, растяжка, гибкость | Стрейчинг, растяжка, гибкость |
| Целевая аудитория | Люди, желающие развить гибкость | Люди, желающие развить гибкость |
| Терминология | Фитнес-стрейчинг | Фитнес-стрейчинг |
| Позиционирование | Тренировки по растяжке | Тренировки по растяжке |

## 🚀 Быстрый старт

1. **Переключиться на банковский режим:**
   ```bash
   npm run content:bank
   npm run dev
   ```

2. **Проверить изменения в браузере**

3. **Вернуться к оригиналу:**
   ```bash
   npm run content:original  
   npm run dev
   ```

## 📞 Поддержка

Если возникли проблемы:
- Проверьте статус: `npm run content:status`
- Всегда можно вернуться: `npm run content:original`
- Резервные копии сохраняются автоматически
