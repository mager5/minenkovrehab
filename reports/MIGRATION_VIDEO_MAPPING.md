Наличие preferred path в локальном backup подтверждает asset/candidate resolver, но не назначает ему UUID строки videos и не доказывает текущий production ответ. Не импортировать такие объекты как новые уроки без решения владельца.

Во всех шести строках duration в dump=NULL. Локальная длительность вычисляется только чтением ISO-BMFF mvhd (не просмотр содержимого); — означает отсутствие/неподдерживаемый контейнер. Файлы/архив не изменяются, ffprobe отсутствует. Для V2–V6 точного file_path в storage нет; найден единственный файл с тем же basename внутри My Bucket. Эти длительности относятся к кандидатам, совпадение имени не доказывает совпадение байтов с утраченным исходным объектом. Перед переносом нужен явный разбор этих storage paths.

Сравнение всех байтов двух локальных кандидатов stage-3 (размер + SHA-256, значения digest не выводятся): не совпадают. Для V3 это файл, найденный по basename, а не объект по исходному UUID-пути; название и одинаковая длительность не подтверждают выбор урока или переназначение source metadata без решения владельца.
