## Блокеры и порядок обновлений

1. **Next 13.5.11:** новый SSR сервер публично достижим. Обновить поддерживаемую ветку вместе с React/Node/eslint-config-next, затем изолированный build и весь Auth/CSRF/checkout/SSR regression. npm предлагает 16.4.0; это кандидат, не проверенное в этом проекте исправление. Перепроверить свежий audit и [maintainer advisories](https://github.com/vercel/next.js/security/advisories) перед выбором. Cookies/headers/params и middleware/proxy меняются между major.
2. **Critical runtime dependency Swiper:** ImageCarousel импортирован product client. Конфигурация статическая, поэтому путь prototype pollution от атакующего не подтверждён; всё же до выпуска обновить/заменить пакет и проверить карусели. [Maintainer advisory](https://github.com/nolimits4web/swiper/security/advisories/GHSA-hmx5-qpq5-p643).
3. **HeyGen → protobufjs / UTF8:** avatar2 и InteractiveAvatar импортируют SDK. До выпуска исключить необязательные avatar функции/SDK либо обновить цепочку вне всех текущих диапазонов, проверить transport и закрыть diagnostic token logging в legacy avatar2. Отключение API не удаляет vulnerable client bundle.
4. **Неиспользуемые production цепочки:** axios/form-data/follow-redirects, nodemailer, Resend/Svix/uuid — удалить после проверки legacy consumers либо обновить. Critical form-data не используется новым auth/payment; не считать её исправленной только из-за отсутствия импорта. Supabase/ws удалить после замены legacy видео/admin, иначе обновить parent lock.
5. **Build/CI:** Tailwind/PostCSS (все копии), glob/parser цепочки, Jest, ESLint/typescript-eslint, lint-staged/serve. Обновлять согласованными группами; Tailwind major требует CSS/visual regression. Dev-only не является remote production exploit, но блокирует доверенную сборку из непроверенных PR с секретами, если такие CI процессы включены (инфраструктура CI не проверялась).
6. После каждой группы: точные версии/lock, npm ci --ignore-scripts в чистой среде, full/prod/backend audit, migration build, 21 платежный тест + Auth/SSR/browser/import, unit/lint/visual tests соответствующей группы. Не выпускать с unresolved critical/runtime high без конкретного доказательства недостижимости и согласованного решения.

## Условия Next advisories

Не все Next advisories достижимы одинаково. Image optimizer отключён images.unoptimized=true — AVIF/optimizer пути не используются штатными компонентами; Windows RCE не соответствует проверенному macOS/Linux плану. Нет i18n, rewrites и use server/Server Actions в текущих исходниках; эти отдельные условия не обнаружены. App Router/RSC, middleware redirects и публичный SSR есть; поэтому общий framework upgrade остаётся блокером. Database entitlement checks выполняются также в SSR/API и не полагаются только на middleware. Public product SSG остаётся и требует проверки cache fixes. Без exploit-теста эти условия не являются утверждением безопасности.

Дополнительная точность для dev инструментов: glob CLI injection требует -c/--cmd, такой вызов не найден; lodash template/unset/omit, YAML merge, ajv $data и Babel sourceMappingURL не используются входящим auth/payment API. Недоверенные source files/PR могут попадать в build tooling, поэтому обновления нужны. Полный обезличенный snapshot advisories и package scope: dependency-audit-20261010.json.
